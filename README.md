## Sector Overview & Market Dynamics

The global architectural design and interior floor plan software sector represents an estimated market size of **$5.4B to $11.9B**, expanding at a 6.5%–15.5% CAGR driven by rapid cloud migration, 3D spatial visualization, and generative AI design tools. The market is **moderately fragmented**: while enterprise CAD/BIM heavyweights (e.g., Autodesk, Trimble, Nemetschek) concentrate large commercial architecture and engineering contracts, the floor-planning, interior layout, and virtual staging space remains fragmented across numerous competitive SaaS point solutions, specialized browser tools, and AI startups serving freelancers, builders, and DIY consumers.

## Open-Source GitHub Projects



- **[egmalt/house-planner](https://github.com)**  

  Lightweight open-source interactive house and floor plan layout tool focused on intuitive room drafting, spatial arrangement, and clean architectural visualization.



- **[Sweet Home 3D (Desktop & JS Engine)](https://github.com)**  

  Flagship open-source interior design and floor plan application enabling 2D wall/room drafting with simultaneous real-time 3D preview and photorealistic rendering.



- **[FreeCAD (BIM & Arch Workbench)](https://github.com)**  

  Comprehensive open-source parametric 3D CAD and Building Information Modeling (BIM) platform featuring dedicated architectural walls, roofs, stairs, and IFC export tools.



- **[Bonsai (formerly BlenderBIM Add-on)](https://github.com)**  

  Full-featured open-source native IFC/BIM authoring environment built on Blender for complete architectural floor plans, construction documentation, and 3D modeling.



- **[LibreCAD](https://github.com)**  

  Fast, lightweight open-source 2D CAD drafting application supporting DXF files, precision layers, snapping, and architectural floor plan blueprints.



- **[QCAD (Community Edition)](https://github.com)**  

  Cross-platform open-source 2D CAD system tailored for technical architectural drawings, floor plans, schematics, and DWG/DXF interoperability.



- **[Blueprint3D (furnishup/blueprint3d)](https://github.com)**  

  Open-source Three.js-powered web framework for building interactive 2D floor plan editors and real-time 3D interior room configurators in HTML5/JavaScript.



- **[Planner3D / React-Planner (cvdlab/react-planner)](https://github.com)**  

  Modular open-source React and Three.js component library for embedding 2D floor plan drawing and 3D architectural walkthroughs into web applications.



- **[OpenSCAD](https://github.com)**  

  Script-based open-source parametric 3D CAD modeler ideal for programmatic architectural layouts, modular structural components, and reproducible floor plan geometry.



- **[Archipack (for Blender)](https://github.com)**  

  Open-source parametric architectural primitive generator for Blender providing instant walls, windows, doors, stairs, roofs, and 2D-to-3D floor plan workflows.



### Additional Strong Open-Source Options



- **[IfcOpenShell](https://github.com)** for open-source Industry Foundation Classes (IFC) BIM parsing, geometry engine processing, and architectural data pipelines.

- **[Floorplan.js & OpenFloorPlan](https://github.com)** for lightweight browser-based SVG/Canvas 2D floor plan editors.

- **[BRL-CAD](https://github.com)** for solid constructive geometry (CSG) modeling and structural engineering analysis.

- **[Solvespace](https://github.com)** for lightweight parametric 2D/3D constraint-based mechanical and architectural drafting.

- **[Blender + MeasureIt ARCH](https://github.com)** for generating annotated architectural floor plans, elevations, and construction sheets directly from 3D models.



**Frameworks for building custom systems**: Combine **FreeCAD (BIM)** or **Blender + Bonsai** for full architectural BIM documentation, **LibreCAD** for 2D DXF blueprints, and **Sweet Home 3D** or **Blueprint3D** for rapid interior floor plan visualization.
