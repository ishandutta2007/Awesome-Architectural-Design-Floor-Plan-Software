# Awesome-Architectural-Design-Floor-Plan-Software

## Top Architectural Design & Floor Plan Software Ecosystem



**Curated List of SaaS/Hosted Platforms & Open-Source GitHub Projects**  

*Focused on 2D/3D Floor Plan Design, BIM Modeling, Parametric Architecture, Interior Layout & CAD Drafting*  

**Last updated: November 2026**



This repository tracks notable **SaaS/hosted platforms** and **open-source projects** for **Architectural Design & Floor Plan Software**. These tools draft, model, visualize, render, and document residential and commercial floor plans, 3D interior layouts, and Building Information Modeling (BIM) projects across web browsers, desktop CAD workstations, and self-hosted environments.



**Examples** include Planner 5D, Floorplanner, RoomSketcher, Cedreo, Foyr Neo, Coohom, SmartDraw, Sweet Home 3D Cloud, SketchUp Web, Homestyler, and egmalt/house-planner (the category leaders and popular runtimes). 



**Open-source emphasis**: This section is heavily expanded with every major active project for open-source 2D/3D floor plan drafting, full-featured BIM modeling, parametric architectural CAD, and browser-based room planners — ideal for architects, interior designers, homeowners, civil engineers, and developers building transparent spatial design tools.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms



- **[Planner 5D](https://planner5d.com)**  

  Cloud-based AI-assisted 2D and 3D home design and floor plan tool featuring automated plan recognition, interior furnishing catalogs, and photorealistic snapshots.



- **[Floorplanner](https://floorplanner.com)**  

  Browser-based interactive 2D/3D floor plan platform widely used by real estate professionals and interior designers for rapid space planning and virtual staging.



- **[RoomSketcher](https://roomsketcher.com)**  

  Cross-platform cloud floor plan and home design software offering 2D/3D floor plans, live 3D walkthroughs, and high-resolution architectural visualizations.



- **[Cedreo](https://cedreo.com)**  

  Cloud 3D home design software tailored for home builders, remodelers, and contractors to generate 2D floor plans and photorealistic exterior/interior renders quickly.



- **[Foyr Neo](https://foyr.com)**  

  Browser-native interior design and floor plan platform combining 2D drafting, 3D modeling, AI-assisted lighting, and fast cloud rendering.



- **[Coohom](https://coohom.com)**  

  Cloud-based 3D interior design and floor plan suite offering real-time rendering, parametric furniture customization, and virtual showroom tours.



- **[Homestyler](https://homestyler.com)**  

  Web-based 3D floor planner and interior decoration platform featuring brand-name furniture catalogs, custom modeling, and cloud rendering.



- **[SketchUp Web (Trimble)](https://sketchup.com)**  

  Browser-based 3D architectural modeling software enabling quick massing, floor plan extrusion, and Trimble Connect cloud file storage.



- **[SmartDraw](https://smartdraw.com)**  

  Cloud diagramming and CAD floor plan application featuring architectural templates, automated dimensioning, and Visio/AutoCAD file interoperability.



- **[Sweet Home 3D Online / Cloud](https://sweethome3d.com)**  

  Web-hosted edition of Sweet Home 3D allowing users to draw house plans, arrange furniture, and preview 3D walkthroughs directly in a browser.





## Open-Source GitHub Projects



- **[egmalt/house-planner](https://github.com)**  

  Lightweight open-source interactive house and floor plan layout tool focused on intuitive room drafting, spatial arrangement, and clean architectural visualization.



- **[Sweet Home 3D (Desktop & JS Engine)](https://github.com)**  

  Flagship open-source interior design and floor plan application enabling 2D wall/room drafting with simultaneous real-time 3D preview and photorealistic rendering.



- **[FreeCAD (BIM & Arch Workbench)](https://github.com)**  

  Comprehensive open-source parametric 3D CAD and Building Information Modeling (BIM) platform featuring dedicated architectural walls, roofs, stairs, and IFC export tools.



- **[Bonsai (formerly BlenderBIM Add-on)](https://github.com)**  

  Full-featured open-source native IFC/BIM authoring environment built on Blender for complete architectural floor plans, construction documentation, and 3D modeling.



- **[LibreCAD](https://github.com)**  

  Fast, lightweight open-source 2D CAD drafting application supporting DXF files, precision layers, snapping, and architectural floor plan blueprints.



- **[QCAD (Community Edition)](https://github.com)**  

  Cross-platform open-source 2D CAD system tailored for technical architectural drawings, floor plans, schematics, and DWG/DXF interoperability.



- **[Blueprint3D (furnishup/blueprint3d)](https://github.com)**  

  Open-source Three.js-powered web framework for building interactive 2D floor plan editors and real-time 3D interior room configurators in HTML5/JavaScript.



- **[Planner3D / React-Planner (cvdlab/react-planner)](https://github.com)**  

  Modular open-source React and Three.js component library for embedding 2D floor plan drawing and 3D architectural walkthroughs into web applications.



- **[OpenSCAD](https://github.com)**  

  Script-based open-source parametric 3D CAD modeler ideal for programmatic architectural layouts, modular structural components, and reproducible floor plan geometry.



- **[Archipack (for Blender)](https://github.com)**  

  Open-source parametric architectural primitive generator for Blender providing instant walls, windows, doors, stairs, roofs, and 2D-to-3D floor plan workflows.



### Additional Strong Open-Source Options



- **[IfcOpenShell](https://github.com)** for open-source Industry Foundation Classes (IFC) BIM parsing, geometry engine processing, and architectural data pipelines.

- **[Floorplan.js & OpenFloorPlan](https://github.com)** for lightweight browser-based SVG/Canvas 2D floor plan editors.

- **[BRL-CAD](https://github.com)** for solid constructive geometry (CSG) modeling and structural engineering analysis.

- **[Solvespace](https://github.com)** for lightweight parametric 2D/3D constraint-based mechanical and architectural drafting.

- **[Blender + MeasureIt ARCH](https://github.com)** for generating annotated architectural floor plans, elevations, and construction sheets directly from 3D models.



**Frameworks for building custom systems**: Combine **FreeCAD (BIM)** or **Blender + Bonsai** for full architectural BIM documentation, **LibreCAD** for 2D DXF blueprints, and **Sweet Home 3D** or **Blueprint3D** for rapid interior floor plan visualization.

## Disclaimer



- This is a **community-curated** list — not exhaustive and not an endorsement.

- Floor plans and architectural drawings generated with consumer or open-source tools must be reviewed and stamped by a licensed architect or structural engineer before construction permitting.

- Verify DXF, DWG, and IFC file compatibility when exchanging plans across proprietary and open-source CAD/BIM platforms.
